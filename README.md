# Linkup

Linkup é um aplicativo móvel que facilita a criação e gestão de eventos sociais, permitindo que os usuários se conectem e participem de atividades em grupo de forma prática e organizada.

## 🚀 Funcionalidades

- **Criação de Eventos** → Permite aos usuários criar eventos personalizados com detalhes como data, hora, local e descrição.
- **Convites e Participação** → Facilita o envio de convites e o gerenciamento de confirmações de presença.
- **Notificações** → Envia atualizações em tempo real sobre mudanças nos eventos ou novas atividades.

## 🛠️ Tecnologias Utilizadas

- **Swift** → Linguagem principal do desenvolvimento.
- **SwiftUI** → Framework para construção da interface do usuário.
- **Core Data** → Gerenciamento de persistência de dados.
- **Tests** → Testes automatizados para garantir a estabilidade do app.
